# Næring i Nord

Ny fler-siders nettside for Næring i Nord, bygget som statisk nettsted i `dist/`.

Sider: forside, tjenester, team, om oss, arbeid/galleri, kontakt, personvern og vilkår.

Designet følger en bevisst enkel profil uten falske tellere, falske anmeldelser, overdrevne animasjoner, AI-bilder eller generisk markedsføringsspråk.
